# После тебя

Короткая one-thumb arcade-игра о комнате, которая помнит ваши шаги. Чем дольше идёшь, тем ближе собственное эхо. Собирайте огоньки, не встречайтесь с эхом и продержитесь минуту.

## Играть

Откройте `app/src/main/assets/index.html` в браузере или запустите Android-приложение. Игра полностью офлайн, без аккаунтов, рекламы и сторонней аналитики.

## Сборка Android

Откройте проект в Android Studio (JDK 17, Android SDK 35) или запустите `./gradlew assembleRelease bundleRelease`. У релизной сборки включена подпись ключом из GitHub Actions Secrets. В GitHub Releases публикуются подписанный APK для установки и AAB для Google Play. Google Play для новых приложений требует Android App Bundle (AAB); APK оставлен для прямой установки/тестирования.

Для воспроизводимой сборки и публикации релиза запустите workflow **Build Android release** или поставьте тег версии вида `v1.0.0`. CI скачивает официальные Android-зависимости, собирает APK и AAB и прикладывает оба файла к релизу. Не храните signing keystore в репозитории.

### Локальная сборка

Откройте проект в Android Studio с JDK 17 и Android SDK 36 либо установите Gradle 8.11.1:

```sh
gradle assembleDebug
```

## Управление

Свайп в сторону или экранные стрелки — один шаг. Собирайте свет, увеличивайте серию, не встречайте своё эхо. Сбор света добавляет секунды. Рекорд хранится только на устройстве.
